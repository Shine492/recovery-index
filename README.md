# 主恢復內容索引

在自己的電腦上執行的搜尋工具：輸入一句話找出處，或輸入幾個詞找出同時提到它們的段落。

**這裏只有程式，不含任何書籍內容。** 第一次執行時，程式會在你的電腦上從各個原網站下載資料並建立索引，之後就在你自己的電腦上搜尋。各來源內容的版權屬於原出版者，本工具僅供個人查考使用，請勿將下載的資料公開散布。

| 來源 | 方式 | 內容 |
|---|---|---|
| 聖經恢復本（recoveryversion.com.tw） | 下載到本機 | 經文、註解、書介、綱目 |
| 生命讀經（lsmchinese.org） | 下載到本機 | 1,984 篇 |
| 倪柝聲文集（christiansquare.org） | 下載到本機 | 62 冊（原文簡體，顯示時轉繁體） |
| 特會訓練綱要（lsmchinese.org/outlines.html） | 下載到本機 | 2006 年起的綱要 PDF，用 Windows 內建文字辨識（OCR）取得文字，可能有少數錯字 |
| 肯定與否定（lsmchinese.org/a&c） | 下載到本機 | 60 篇 |
| 李常受文集（cwwl.twgbr.org） | 每次搜尋時即時查詢該站 | 全文 |

## 安裝與使用

需要：**Windows 10 或 11**、約 **2 GB** 硬碟空間、網路。

1. **安裝 Python**：到 <https://www.python.org/downloads/> 下載安裝（3.10 以上）。安裝畫面最下方的 **「Add python.exe to PATH」一定要打勾**。
2. **下載本程式**：按本頁上方綠色的 **Code** 按鈕 → **Download ZIP**，下載後解壓縮到任一資料夾。
3. **雙擊 `啟動搜尋網站.bat`**。
   - 第一次會自動安裝需要的套件、下載資料並建立索引，約需 40 分鐘到 1 小時，期間請不要關閉黑色視窗。
   - 完成後瀏覽器會自動打開 <http://localhost:8765>。
4. 之後每次要用，雙擊 `啟動搜尋網站.bat` 就好（幾秒內開好）。關掉黑色視窗就停止。

### 手機使用

手機和電腦連同一個 Wi-Fi 時，在手機瀏覽器輸入黑色視窗裏「手機請開：http://…」那一行的網址即可。電腦要開著並執行本程式。第一次啟動時 Windows 可能會詢問是否允許 Python 通過防火牆，要讓手機連線請選擇允許。

### 特會訓練綱要需要繁體中文文字辨識

綱要的 PDF 沒有文字層，需要 Windows 內建的繁體中文 OCR。語言設定為繁體中文的 Windows 通常已內建；如果啟動時顯示「先略過綱要」，請到 **設定 → 時間與語言 → 語言與地區** 新增「中文（繁體，台灣）」，然後在本資料夾執行：

```
python crawl.py outl
python build_index.py
```

## 搜尋方式

輸入框按 **Enter** 搜尋，**Shift+Enter** 換行。結果左側可依來源篩選。

### 找出處（貼上句子或整段）

- 輸入的文字依句號、問號、驚嘆號、分號、換行切成句子，每句分別比對。
- 比對前先把繁簡、異體字（裏/裡/里、著/着、纔/才、祂/他…）統一，並去掉標點。
- 列出相似度達門檻（預設 90%，可調）的句子，類型有：**完全相同**、**原文包含此句**（輸入是原文一句的一部分）、**整句相似**、**部分相似**。

### 關鍵詞（輸入幾個詞，用空白隔開，最多 4 個）

例如 `重生 神的國 生命`。會找出**同一段**裏全部出現這些詞的地方，並列出約 30 字的原文（詞彼此距離較遠時，各取一小段，用「…」連起來）。

- 「同一段」：生命讀經、倪柝聲文集、李常受文集、肯定與否定是原文的一個段落；恢復本是一節經文或一則註解；綱要是一個綱目點。
- 「方式」選「自動判斷」時：沒有標點、每個詞不超過 10 字，就當關鍵詞搜尋；否則當句子找出處。

### 上傳綱要（逐點找出處）

切到「上傳綱要」分頁，把綱要檔拉進去（或點一下選檔案），支援 **Word .docx、PDF、純文字 .txt**。程式會：

1. 把綱要拆成一個一個綱目點（依段落和開頭的編號：壹、一、1、a…）。
2. 去掉每一點開頭的編號，以及句尾、括號裏的經文出處，只拿那一點本身的話去比對。
3. 逐點找出處或相似度達門檻（預設 80%，可調）的句子，顯示最高相似度；點開可看前幾筆出處和原文。

可以只看未找到的點，也可以按「複製結果」把每一點和它的出處複製成文字。

- **Word 檔和有文字層的 PDF 拆得最準。** PDF 會依每行的位置和字級來拆：編號獨立成一行、編號是全形字母（ａｂｃ）、數字編號是小圖片、每點下面附了經文，這些排版都能處理。
- 沒有文字層的 PDF（如特會網站上的綱要）要靠文字辨識，拆點和文字都可能有誤。
- 相似度相同時，生命讀經、恢復本、文集會排在特會訓練綱要前面（上傳的綱要常會對到同一份綱要本身）。
- 舊版 `.doc` 不支援，請先另存成 `.docx`。
- 勾選李常受文集時每一點都要連線查詢，點數多的綱要會比較久。

### 連到原文

每筆結果都有一個連到原網站的連結（標題本身也是連結）：

| 來源 | 點了會到哪裏 |
|---|---|
| 生命讀經、肯定與否定、倪柝聲文集 | 開啟那一篇，並自動捲到那一句、標示出來（Chrome、Edge、Safari 支援；倪柝聲文集原網頁是簡體，偶爾會對不上而停在頁首） |
| 聖經恢復本 | 開啟該書該章（註解要在該頁點經文上的註號才會顯示） |
| 特會訓練綱要 | 開啟那一篇的原 PDF |
| 李常受文集 | 該站沒有固定網址，會自動到該站搜尋那句話，結果頁上有冊、章、頁碼 |

### 限制

- 李常受文集的網站只能找一字不差的字串，所以找出處時是從每句挑幾個片段去查它，再把回傳的段落逐句評分；片段剛好都有改字時可能漏掉。
- 關鍵詞搜尋每個來源最多列出前 60 筆；本機資料最多檢查前 4,000 段，太常見的詞請再加一個詞縮小範圍。
- 綱要中有少數連結在原網站上已失效，無法收錄。

## 更新資料

網站內容有更新時，刪掉 `data\cache` 和 `data\index.db`，再雙擊 `啟動搜尋網站.bat`（綱要的辨識結果存在 `data\ocr`，不會重做）。也可以手動執行：

```
python crawl.py          # 下載全部（可只抓一個：python crawl.py rv / ls / nee / ac / outl）
python build_index.py    # 建立索引
```
